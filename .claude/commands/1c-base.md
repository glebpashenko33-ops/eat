---
description: Подключить существующую базу 1С, обновить её выгрузку из базы или показать список баз
argument-hint: add | refresh [id] | list
---

Аргументы: `$ARGUMENTS`. Без аргументов выполни `list`.

## add — подключить базу

1. Одним сообщением спроси у пользователя:
   - где база: файловая (путь к каталогу) или серверная (сервер 1С и имя базы);
   - пользователь и пароль 1С с правами администратора;
   - версия платформы, если она отличается от `v8path` в `.v8-project.json`;
   - **рабочая ли это база**, в которой работают пользователи (тогда `protected: true`);
   - подключены ли основная конфигурация или расширения к хранилищу (путь, пользователь, пароль).

   Предложи короткий латинский `id` (например, `ut-romashka`) и человекочитаемое имя.
2. Зарегистрируй базу навыком `/db-list add` с этими данными. Затем допиши в её запись в `.v8-project.json`:
   - `"configSrc": "bases\\<id>\\cf"`;
   - `"protected": true` или `false`.
3. Выгрузи основную конфигурацию для анализа: `/db-dump-xml <id> bases/<id>/cf -Mode Full`. Она только для чтения и в git не попадает. Предупреди, что для большой типовой конфигурации это 10–30 минут.
4. Получи список расширений: `/db-cfe-admin list <id>`. Для каждого расширения:
   - выгрузи исходники: `/db-dump-xml <id> bases/<id>/cfe/<Имя> -Extension <Имя> -Mode Full`;
   - добавь `{ "name": "<Имя>", "src": "bases\\<id>\\cfe\\<Имя>" }` в `extensions` записи базы (и `repository`, если расширение в хранилище).
5. Создай `bases/<id>/NOTES.md`:
   - конфигурация, версия и режим совместимости (из `bases/<id>/cf/Configuration.xml`), платформа;
   - тип базы и `protected`;
   - таблица расширений: имя, назначение (Patch, Customization или AddOn), что делает — 1–2 фразы по коду, безопасный режим.

   Этот файл — память о базе. Дополняй его, когда узнаёшь что-то важное.
6. Закоммить `bases/<id>/cfe` и `bases/<id>/NOTES.md` с сообщением «<id>: расширения из базы (исходное состояние)».
7. Попроси пользователя выйти и запустить `.\radar.ps1 <id>`: анализатор кода подхватит выгрузку этой базы.

## refresh [id] — забрать актуальное состояние из базы

База по умолчанию — `default` из `.v8-project.json`.

1. Основная конфигурация: `/db-dump-xml <id> bases/<id>/cf -Mode Changes`, а если выгрузки нет — `-Mode Full`.
2. Сверь список расширений в базе (`/db-cfe-admin list <id>`) с `extensions` записи. Новые расширения добавь и выгрузи. Об удалённых из базы сообщи, их исходники не удаляй.
3. Перевыгрузи каждое расширение в его каталог `-Mode Full`. Если `git status` показывает изменения в `bases/<id>/cfe`, значит расширение меняли в базе мимо этого репозитория. Кратко опиши, что изменилось, и закоммить: «<id>: синхронизация расширений из базы».
4. Если появились новые расширения, попроси перезапустить `.\radar.ps1 <id>`.

## list — показать базы

Таблица из `.v8-project.json`: id, имя, файловая или серверная, `protected`, расширения, отметка текущей базы (`default`). Пароли не выводи.
