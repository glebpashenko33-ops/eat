# Радар

Окружение, в котором Claude Code пишет **расширения 1С** и **исправляет существующие** прямо в ваших базах. Основная конфигурация баз не меняется, работа идёт только через расширения, а перед каждой загрузкой делается бэкап.

```
/1c-task при проведении «Реализации товаров» не заполняется склад в табличной части
/1c-task добавь в карточку контрагента поле «Куратор» (пользователь) и выведи его в список
```

## Как это работает

| Шаг | Что делает агент |
|---|---|
| 1. Сверка | Перевыгружает расширение из базы и сверяет с git: если его меняли мимо репозитория, сначала фиксирует эти изменения |
| 2. Разбор | Исправление или доработка; при необходимости спрашивает текст ошибки и шаги воспроизведения |
| 3. Исследование | Ищет код и метаданные в выгрузке базы, строит граф вызовов, находит причину ошибки, сверяет методы со справкой платформы |
| 4. Правка | Новое расширение или существующее; заимствует объекты, ставит перехваты `&Перед`, `&После`, `&ИзменениеИКонтроль`, пишет код |
| 5. Проверка | Валидация расширения, сверка с основной конфигурацией, диагностики кода, проверка запросов |
| 6. Загрузка | Бэкап `.cfe`, загрузка, обновление (для рабочих баз — динамическое и только после вашего «да»), проверка применимости и синтаксиса в базе |
| 7. Сдача | Коммит, инструкция «что открыть и нажать», путь к бэкапу и команда отката |

Инструменты:
- [bsl-analyzer](https://github.com/itrous/bsl-analyzer) — анализ кода по XML-выгрузке, без подключения к базе: метаданные, поиск, граф вызовов, справка платформы, диагностики.
- [cc-1c-skills](https://github.com/Nikolay-Shirokov/cc-1c-skills) — навыки для расширений, форм, макетов, СКД и пакетного режима конфигуратора.

В ваши базы ничего служебного не ставится.

## Что нужно

- Windows 10/11, PowerShell 5.1+.
- Платформа 1С:Предприятие 8.3 с Конфигуратором; права администратора в базах.
- [Claude Code](https://docs.anthropic.com/en/docs/claude-code), Git, Python 3.9+.

## Установка

```powershell
git clone https://github.com/glebpashenko33-ops/radar.git
cd radar
powershell -ExecutionPolicy Bypass -File setup\install.ps1
```

Установщик сам найдёт самую новую платформу в `C:\Program Files\1cv8`. Другую можно указать ключом `-PlatformPath "C:\Program Files\1cv8\8.3.24.1691\bin"`.

## Работа

1. Запустите Claude Code и подключите базу. Агент спросит, где она, под каким пользователем и **рабочая ли это база**. Потом он выгрузит конфигурацию и все расширения и закоммитит их исходное состояние.

   ```powershell
   .\radar.ps1
   ```

   ```
   /1c-base add
   ```

2. Перезапустите с этой базой, чтобы анализатор кода подхватил её выгрузку:

   ```powershell
   .\radar.ps1 ut-romashka
   ```

3. Ставьте задачи:

   ```
   /1c-task <что исправить или доработать>
   ```

Другие команды:

| Команда | Что делает |
|---|---|
| `/1c-base list` | Список баз, текущая отмечена |
| `/1c-base refresh` | Забрать из базы актуальную конфигурацию и расширения (после обновления типовой или чужих правок) |
| `/1c-rollback <Расширение>` | Вернуть расширение к бэкапу перед последней загрузкой |
| `.\radar.ps1 <id>` | Переключиться на другую базу |

## Что где лежит

```
bases/
  ut-romashka/
    cf/              выгрузка основной конфигурации (только для анализа, не в git)
    cfe/<Имя>/       исходники расширений (в git — история всех правок)
    backup/          .cfe-бэкапы перед каждой загрузкой (не в git)
    NOTES.md         что агент знает о базе
```

## Безопасность

- Основная конфигурация не загружается и не обновляется: только расширения.
- Перед каждой загрузкой — бэкап `.cfe`, откат одной командой.
- Для рабочих баз (`protected`) агент показывает, что меняется, ждёт подтверждения и обновляет динамически, не выгоняя пользователей.
- Данные в базах агент не меняет.
- Пароли хранятся только в `.v8-project.json`, который не попадает в git.
- Код и выгрузка конфигурации отправляются в модель Anthropic. Если конфигурация клиента под NDA, согласуйте это с ним.
