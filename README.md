# eat — рацион под бюджет по живым ценам

Вы вводите сумму, например 5000 ₽ на неделю. Приложение подбирает меню с рецептами на каждый день и составляет список покупок по магазинам.

**Что учитывается при подборе:**
- бюджет: итог не больше заданной суммы, с учётом фасовки (покупаются целые упаковки);
- нормы питания: калории, белок, жиры, клетчатка, витамин C, кальций, железо, овощи и фрукты;
- разнообразие: блюда за период не повторяются, белок и гарнир чередуются, новое меню не повторяет прошлое;
- живые цены сетей: Пятёрочка, Магнит, Чижик, Перекрёсток, Лента, Метро, Ашан, ВкусВилл, Дикси.

Внутри 103 рецепта: завтраки, супы, вторые блюда и перекусы, у каждого граммовка и шаги приготовления. Каталог — 70 базовых продуктов с составом. Порции каждого человека рассчитываются под его норму калорий по формуле Миффлина — Сан Жеора.

## Откуда цены

Открытого API с ценами нет ни у одной сети. Сборщик (`collector/`) открывает сайт сети в обычном браузере, ищет каждый продукт и забирает цены. Источники — собственные ответы API сайта, встроенные в страницу данные и карточки товаров. От формата конкретной сети сборщик не зависит. Из найденных товаров он берёт самые дешёвые за кг (л, шт) с подходящим названием и правдоподобной ценой.

Многие сети, например Пятёрочка, Перекрёсток, Чижик и Дикси, не пускают зарубежные серверы. Поэтому сборщик запускается **на вашем компьютере в России**. Цены Магнита дополнительно обновляет GitHub Actions три раза в день, даже когда компьютер выключен (`.github/workflows/prices.yml`).

Что проверено на настоящих сайтах (с сервера вне России, ноябрь 2026):

| Сеть | Результат |
|---|---|
| Магнит | ✅ цены собираются, и через браузер, и через прямой API |
| Лента | ✅ цены собираются |
| Пятёрочка, Перекрёсток, Чижик, Дикси | ⛔ блокируют зарубежные IP, нужен запуск из России |
| Метро | ⛔ поиск не отвечает зарубежному серверу |
| Ашан, ВкусВилл | ⛔ не открылись с сервера |

Сети с пометкой ⛔ с вашего компьютера должны работать так же, как Магнит и Лента. Если какая-то не соберётся, запустите `python -m collector diagnose <сеть> "гречка"` и пришлите вывод вместе со снимком `diagnose-<сеть>.png`.

## Установка на Windows

1. Установите [Python 3.11+](https://www.python.org/downloads/). При установке отметьте «Add python.exe to PATH».
2. Скачайте репозиторий: `git clone` или Code → Download ZIP.
3. Запустите `setup.bat`:
   - он поставит зависимости и откроет Edge с сайтами сетей;
   - на каждой вкладке выберите свой город и ближайший магазин (от этого зависят цены) и закройте браузер;
   - в конце скрипт предложит обновлять цены каждый день автоматически.
4. Запустите `prices.bat`, чтобы собрать цены. Это займёт около 10 минут: все сети опрашиваются параллельно.
5. Запустите `start.bat`, чтобы открыть приложение. В консоли появится адрес вида `http://192.168.1.5:8080`. Откройте его с телефона в той же Wi-Fi и добавьте на главный экран.

## Команды

```bash
python -m collector setup                     # выбрать город и магазин на сайтах сетей
python -m collector collect                   # собрать цены во всех сетях
python -m collector collect --stores magnit,lenta --limit 5   # быстрая проверка
python -m collector diagnose lenta "молоко"   # что сайт отдаёт на запрос
python -m collector serve                     # приложение на http://localhost:8080
```

Адреса поиска сетей хранятся в `collector/stores.json`. Если сеть поменяла сайт, обычно достаточно поправить там строку `search`.

## Устройство

| Путь | Что это |
|---|---|
| `web/` | приложение: обычная страница без сервера и сборки |
| `web/planner.js` | подбор меню (имитация отжига) и список покупок с выбором магазинов |
| `web/data/products.json` | продукты: состав на 100 г, ориентировочная цена, правила поиска в магазинах |
| `web/data/recipes.json` | рецепты: граммовка на порцию, время, шаги |
| `web/data/prices.json` | цены, собранные на компьютере |
| `web/data/prices.ci.json` | цены Магнита из GitHub Actions |
| `collector/` | сборщик цен (Python + Playwright) |
| `tests/` | тесты: `node tests/planner.test.js` и `python -m pytest tests` |

Товары без живой цены в выбранных сетях считаются по ориентиру и помечаются «≈».
